官方入口里「淋浴」和「洗澡」是两个页面，去洗个澡要在手机上戳七八下。这里打开就是它。

下载与安装

只支持 Android 8.0 及以上。安装包约 100 KB，不申请定位、通讯录、短信等权限。

  1. 下载 APK 并安装。系统提示「未知来源」时，允许你正在使用的浏览器安装即可。
  2. 用手机号登录：验证码由完美校园下发，登录成功后凭据只保存在本机。
  3. 账号需要先在官方侧绑定校园卡，否则登录后会提示缺少信息。绑定方式与密码规则以学校通知为准。
  4. 想更方便：先在系统通知设置里给本应用开「允许通知」；想连锁屏也能看码，再打开「实时活动」（ColorOS 叫流体云，澎湃 OS 叫实时动态）。

关于锁屏上的验证码

这是本应用最方便、也最需要你自己权衡的一点。

取码后，验证码会以明文出现在通知栏，开启「实时活动」后还可能出现在 锁屏、状态栏胶囊甚至息屏显示上—— 手机放在桌上、没有解锁，旁边的人也可能直接看到。

不想这样：在系统设置 → 通知 → 本应用里关掉「锁屏」；要连通知栏也不显示，就关掉「允许通知」。

由此产生的费用或其他损失由使用者自行承担。完整说明见 隐私政策第 9 条。

常见问题

锁屏上看不到验证码？

先确认系统里给本应用开了「允许通知」；再确认本应用通知页里的「实时活动」开关（ColorOS 叫「流体云显示实时活动」）已打开。 部分系统还需要单独打开该应用的「锁屏」开关。应用内「设置 → 验证码显示」会显示当前状态，并给出对应提示。

会不会收集我的账号或个人信息？

不会上传到开发者服务器。登录凭据（token）与用户信息只存在本机；请求直接发往完美校园的水控接口。 应用内没有统计 SDK、没有广告、没有崩溃上报。详见隐私政策。

为什么有时取码了却没有通知？

常见的三种原因：通知权限被关掉；系统把通知归到「静默」；或者通知被系统的省电策略拦截。 可以在「设置 → 验证码显示」查看当前状态，按提示去系统设置调整。

支持哪些学校？

凡是使用完美校园「智慧用水」的学校理论上都可用，但各校的水控服务与卡务规则不同， 实际表现可能不一样。遇到问题欢迎在项目主页反馈。

和应用商店里的版本有什么区别？

本项目只通过 GitHub Releases 分发，不上架应用商店。安装包为个人开发者签名，升级时直接覆盖安装即可， 不会丢登录态与设置。
